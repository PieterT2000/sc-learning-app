Design notes: Warm neutrals (#faf9f6 background) feel contemplative, not clinical. Muted blue (#3d5a80) for primary actions grounds the interface without competing with the content. The diff uses green for correct and red for wrong/missing — immediate, no legend needed. The "Why This Matters" reflection sits below the diff, visible without scrolling, placed at the exact moment the user just finished wrestling with the content. Badge progression (earned = gold, unearned = gray) gives a sense of journey without pressure. Mode selector uses icons + one-line descriptions so the difference between Learning/Easy/Hard is obvious at a glance.
